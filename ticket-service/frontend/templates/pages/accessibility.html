הצהרת נגישות / Accessibility Statement

אנו ב-Yalla Balagan מחויבים לספק נגישות שווה לכל המשתמשים.

We at Yalla Balagan are committed to providing equal access to all users.

האתר שלנו עומד בתקן הישראלי ת"י 5568 ברמת AA והמלצות WCAG 2.1.

Our website complies with Israeli Standard IS 5568 Level AA and WCAG 2.1 guidelines.

כלי נגישות / Accessibility Toolbar

באתר שלנו מותקן כלי נגישות מתקדם המאפשר התאמה אישית של חווית הגלישה. הכפתור הכחול בפינה התחתונה של המסך פותח תפריט עם האפשרויות הבאות:

Our website features an advanced accessibility toolbar that allows personalization of the browsing experience. The blue button in the bottom corner of the screen opens a menu with the following options:

התאמות חזותיות / Visual Adjustments

  • גודל גופן / Font Size: 4 רמות הגדלה (רגיל, בינוני, גדול, גדול מאוד) / 4 size levels (default, medium, large, extra large)
  • ניגודיות / Contrast: מצבי ניגודיות גבוהה (כהה, בהיר, הפוך) / High contrast modes (dark, light, inverted)
  • ריווח טקסט / Text Spacing: הגדלת המרווחים בין אותיות ושורות לקריאה נוחה / Increased spacing between letters and lines for comfortable reading
  • הסתרת תמונות / Hide Images: הסרת תמונות לטעינה מהירה יותר / Remove images for faster loading
  • הדגשת קישורים / Highlight Links: הדגשה ויזואלית של כל הקישורים / Visual highlighting of all links

עזרי ניווט / Navigation Aids

  • ניגודיות מקלדת / Keyboard Navigation: מסגרות מודגשות בצהוב לניווט במקלדת / Enhanced yellow outlines for keyboard navigation
  • מדריך קריאה / Reading Guide: קו אופקי העוקב אחר סמן העכבר / Horizontal line following the mouse cursor
  • דלגלתוכן הראשי / Skip to Content: קיצור דרך לדלג על התפריט / Keyboard shortcut to skip navigation

תמיכה קוגניטיבית / Cognitive Support

  • תמיכה בדיסלקציה / Dyslexia Support: גופן OpenDyslexic מיוחד לקריאה קלה יותר / OpenDyslexic font for easier reading
  • גובה שורה / Line Height: 3 רמות של ריווח בין שורות / 3 levels of line spacing
  • ביטול הנפשות / Reduced Motion: הפחתה או עצירה של אנימציות / Reduction or stopping of animations

שמירת העדפות: כל ההגדרות נשמרות באופן אוטומטי ונשארות פעילות בין ביקורים באתר.

Preference Saving: All settings are automatically saved and remain active between visits to the site.
